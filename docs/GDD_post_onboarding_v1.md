# ReefBot — Post-Onboarding Flow v1

## Контекст

После онбординга игрок имеет:
- Названный остров
- Стартовый набор: 🪵×20, 🪨×10, 🎣 удочка
- Статус `ACTIVE`, экран `MAIN`

Задача: провести игрока через первый живой цикл игры — не через туториал, а через **опыт**.

## Главное меню (MAIN)

При каждом открытии главного меню бот отправляет **профильную карточку** — изображение 900×600 с бэкграундом `src/main/resources/img/profile/background.png` и динамическим оверлеем (Java Graphics2D). Под фото — клавиатура.

Карточка показывает: имя острова, стадия, заполненность склада (%), пассивный доход, активная стройка, прогресс ОР.  
Подробный дизайн — в `GDD_profile_card.md`.

```
[📸 profile card image]

━━━━━━━━━━━━━━━
[🏝 Мой остров]  [🏗 Строить]
[📦 Инвентарь]  [🎣 Рыбалка]
```

Если активен гость — добавляется 5-я кнопка на всю ширину:
```
[🤝 Гость на берегу! (осталось 3 ч)]
```

## Акт 1 — Первая рыбалка

### Триггер
Сразу после получения стартового набора (`RECEIVE_STARTER_PACK`) бот показывает главное меню и добавляет подсказку:

```
🎣 В стартовом наборе нашлась старая удочка.
Самое время её испытать — нажми «Рыбалка».
```

### Экран рыбалки (FISHING_MENU)

Игрок видит не просто кнопки — а объяснение каждого варианта.
Кнопки ведут на экран-детку места, откуда можно забросить.

```
🎣 Рыбалка
Уровень рыбака: 1 · ⭐ 0 / 30 XP

Куда забросить удочку?

[🏖 У берега — 1 мин]
[🪨 У рифа — 10 мин]
[🌊 В открытом море — 30 мин]  🔒 ур. 3
```

### Экран выбора места (детали)

При нажатии на место — игрок видит карточку с объяснением **до** того как кидает удочку:

**🏖 У берега**
```
🏖 Рыбалка у берега

Спокойное место у кромки воды.
Быстро, но улов скромный.

⏱ Время: 1 минута
🐟 Улов: 1–3 рыбы
⭐ Опыт: +5 XP
🎲 Редкость: нет

Подходит если хочешь быстро попробовать
или у тебя мало времени.

[✅ Закинуть удочку]  [◀️ Назад]
```

**🪨 У рифа**
```
🪨 Рыбалка у рифа

Рыба здесь крупнее — прячется
под камнями. Стоит подождать.

⏱ Время: 10 минут
🐟 Улов: 4–8 рыб
🐚 Шанс ракушки: 15%
⭐ Опыт: +15 XP

Лучший выбор для ежедневной игры —
хороший баланс улова и времени.

[✅ Закинуть удочку]  [◀️ Назад]
```

**🌊 В открытом море** (разблокируется на ур. 3)
```
🌊 Рыбалка в открытом море

Далеко от берега, глубокая вода.
Богатый улов, но нужно терпение.

⏱ Время: 30 минут
🐟 Улов: 10–20 рыб
🪸 Шанс кораллов: 25%
⭐ Опыт: +35 XP

Идеально: забросил, занялся другим,
вернулся — и вытащил большой улов.

[✅ Закинуть удочку]  [◀️ Назад]
```

Характеристики для реализации:

| Место | Время | Улов | XP | Шанс редкости | Мин. уровень |
|---|---|---|---|---|---|
| 🏖 У берега | **1 мин** | 1–3 🐟 | +5 ⭐ | — | 1 |
| 🪨 У рифа | **10 мин** | 4–8 🐟 + 🐚 | +15 ⭐ | 15% 🐚 | 2 |
| 🌊 В море | **30 мин** | 10–20 🐟 + 🪸 | +35 ⭐ | 25% 🪸 | 3 |

> Минута — для новичка, чтобы сразу почувствовать петлю.
> 10 и 30 минут — когда игрок уже понял механику и хочет оффлайн-игру.

### Экран во время рыбалки

Пока удочка заброшена — кнопка рыбалки в меню меняется:

```
[⏳ Рыбалка (осталось 8 мин)]
```

Нажав — видит статус:

```
⏳ Удочка заброшена у рифа

Осталось: 8 мин
Место: 🪨 У рифа

[◀️ Назад]
```

Отозвать удочку нельзя — учит уважать выбор.

### Экран результата

```
🎉 Улов готов!

Место: 🪨 У рифа
Поймал: 🐟 ×6, 🐚 ×1

Опыт рыбака: +15 ⭐  (всего 15/30)

[✅ Забрать улов]
```

После нажатия — ресурсы добавляются в инвентарь, экран возвращается в MAIN.

## Акт 2 — NPC-гость

### Логика появления

- **Шанс 70%** после завершения любой рыбалки
- **100%** после первой рыбалки в игре (гарантия для онбординга)
- Одновременно может быть только один гость
- Гость активен **4 часа**, потом уходит
- Уведомление: *"🤝 На берегу появился гость!"*

### Кнопка в меню

Пока гость активен — в главном меню появляется кнопка:

```
[🤝 Гость на берегу! (осталось 3 ч 22 мин)]
```

### Экран встречи

```
🧓 Старый рыбак Мариус

«Давненько не видел молодого хозяина на этих берегах.
Я знаю толк в рыбе — давай обменяемся.»

Он предлагает:
  📋 Чертёж «Рыбацкий помост»

В обмен на:
  🐟 ×5

У тебя: 🐟 ×6  ✅

[✅ Принять]  [❌ Отказать]
[◀️ Назад]
```

### Пул NPC и предложений

Каждый гость генерируется случайно из пула:

| Персонаж | Предлагает | Просит | Особенность |
|---|---|---|---|
| 🧓 Мариус (рыбак) | 📋 Чертёж помоста | 🐟×5 | Гарантирован первый раз |
| 🧭 Торговец | 🪵×20 | 🐟×10 | Часто |
| 🧭 Торговец | 🪨×15 | 🐟×8 | Часто |
| ⚓ Капитан | 🐚×3 | 🪵×25 + 🪨×10 | Редко |
| 🧙 Странник | ⭐×50 XP | 🐟×15 | Редко |
| 🏴‍☠️ Подозрительный тип | 🪸×1 | 🐚×5 | Очень редко, риск обмана |

Подозрительный тип с шансом 30% берёт ресурсы и ничего не даёт. Бот пишет:
```
🏴‍☠️ Тип схватил ракушки и растворился в темноте...
Кажется, тебя провели. 😅
```

Это добавляет риск и юмор — игрок запоминает.

### После сделки / отказа

```
✅ Сделка заключена!

Получил: 📋 Чертёж «Рыбацкий помост»
Отдал: 🐟 ×5

🧓 Мариус: «Удачи, хозяин. Береги остров.»

[◀️ Назад в меню]
```

## Акт 3 — Первое строительство

### Если чертёж получен от Мариуса

Бот подсказывает в главном меню:

```
✨ Новый чертёж разблокирован: 🛶 Рыбацкий помост
Открой «Строить» чтобы возвести его.
```

В меню строительства помост подсвечен:

```
🏗 Строить — 🏖 Береговая зона

✨ [🛶 Рыбацкий помост]  Tier 1
   +6 🐟/час
   Стоимость: 🪵×10, 🪨×5
   Время: ⏳ 15 мин
```

### Единый шаблон карточки постройки

Один формат для всех 9 зданий. Плотность информации растёт с тиром —
T1 лаконичный, T3 показывает больше деталей. Структура неизменна.

**T1 — пример: 🛶 Рыбацкий помост**
```
🛶 Рыбацкий помост  · Tier 1

📍 Зона: 🏖 Береговая
⚡ Эффект: +6 🐟/час

💰 Стоимость:
  🪵 10  (есть: 20 ✅)
  🪨 5   (есть: 10 ✅)

⏱ Время постройки: 15 мин
🔁 Окупаемость: ~1 ч 40 мин

[✅ Строить]  [❌ Отмена]
```

**T2 — пример: ⛏ Каменоломня**
```
⛏ Каменоломня  · Tier 2

📍 Зона: ⛰ Холмовая  (нужно 10 ОР ✅)
⚡ Эффект: +5 🪨/час
🏆 Очки развития: +3 ОР

💰 Стоимость:
  🪵 25  (есть: 40 ✅)
  🪨 15  (есть: 8 ❌ — не хватает 7)

⏱ Время постройки: 1 ч

[❌ Недостаточно ресурсов]  [◀️ Назад]
```

**T3 — пример: 🪸 Коралловый ныряльщик**
```
🪸 Коралловый ныряльщик  · Tier 3

📍 Зона: ⚓ Портовая  (нужно 35 ОР ✅)
⚡ Эффект: +3 🪸/час
🏆 Очки развития: +8 ОР
🔗 Требует: 🛶 Рыбацкая пристань ✅

💰 Стоимость:
  🪵 60  (есть: 80 ✅)
  🪨 40  (есть: 45 ✅)
  🐟 20  (есть: 31 ✅)

⏱ Время постройки: 4 ч
🔁 Окупаемость: ~7 ч (по рыночной стоимости 🪸)

[✅ Строить]  [❌ Отмена]
```

**Правила шаблона:**
- Строка зоны показывает `✅` если разблокирована, `🔒 нужно N ОР` если нет
- Строка стоимости показывает `✅` если хватает, `❌ не хватает N` если нет
- Если хоть один ресурс недостаёт — кнопка «Строить» заменяется на «Недостаточно ресурсов»
- Строка prerequisites показывается только у T2/T3
- Строка окупаемости: `стоимость ÷ производство в час`. Для зданий без производства — не показывается
- Строка ОР показывается только у T2/T3

### После завершения строительства

Уведомление:

```
🔔 Рыбацкий помост построен!

Теперь рыба копится сама — возвращайся через
несколько часов и забирай улов.

[🏝 Мой остров]
```

## Уровни рыбака

| Уровень | XP | Разблокирует |
|---|---|---|
| 1 | 0 | 🏖 Берег |
| 2 | 30 XP | 🪨 Риф |
| 3 | 100 XP | 🌊 Открытое море |
| 4 | 250 XP | Улучшенная удочка (больше улов) |
| 5 | 500 XP | Ночная рыбалка (редкий улов) |

> Уровень 2 достигается примерно после 2–3 рыбалок у рифа.
> Прогресс виден в меню рыбалки — мотивирует возвращаться.

- `requestedResource / requestedAmount`

- `accepted: boolean`

## Что даёт этот флоу

За первые ~30 минут игрок:
1. Сделал первый **активный выбор**
2. Подождал и **вернулся** за наградой
3. Встретил **живого персонажа** с историей
4. Принял **торговое решение** (с риском)
5. Построил **первое здание**
6. Понял **пассивную механику**

Всё это — без единой строчки туториала.
